<h2> Overview </h2>

The IoT Box PCB is an ESP32-based control board designed as a simple platform with the ability to advance more, for controlling external high-voltage devices and interfacing with sensors and external modules such as IR.

<h2>Main Components of PCB</h2> 
<ul> <li> <strong>ESP32</strong> — Main microcontroller and control unit </li> 
<li> <strong>4-Channel Mechanical Relay</strong> — Control of external high-voltage devices </li> 
  <li> <strong>DHT11</strong> — Temperature and humidity monitoring </li> 
  <li> <strong>Buzzer</strong> — Audible notifications and system feedback </li> 
  <li> <strong>IR Connector</strong> — Interface for connecting an external IR module </li> 
  <li> <strong>5V / GND Pins</strong> — Power connections for external modules and peripherals </li> </ul>



The board provides multiple hardware interfaces while keeping the design compact and suitable for IoT-based applications.
